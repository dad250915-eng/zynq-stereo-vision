# 报告与协作材料

- ai_collaboration.md：可核实对话节选的说明、历史优化案例与纠错摘要。
- ai_interaction_excerpt.jsonl：真实原话节选，并非完整会话导出。
- optimization_evidence.md：带原始片段来源的优化观察与限制。
- remaining_items.md：最终参赛交付缺项。

设计报告对应报名系统“技术文档”，最终应为PDF并符合匿名与大小要求。当前未把未确认的Word草稿作为最终报告放入仓库。确认最终PDF后可放入此目录，命名design_report.pdf，或在这里给出固定版本的可访问链接。比赛模板中的章节可自行排列，但应覆盖创新、功能、性能资源优化、接口、AI协作、Skill提炼与复现。
