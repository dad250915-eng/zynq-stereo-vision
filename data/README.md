# 历史日志来源

本目录txt是从本对话中用户实际粘贴的串口日志逐行摘取，整理日期为2026-10-31。原始采集日期、各阶段完整版本哈希和统一测试条件在可见记录中不全，因此不补造这些字段。不是本次重新接板采样，也不是自动生成的模拟测量。

historical_serial_excerpt.txt 对应用户最后提供的完整采集日志中连续137～139帧，保留ROI及其后CAPTURE统计。其余三个文件对应早期B/C瓶颈、B/C优化后D仍慢、D优化并行后三个历史阶段。ROI大小与场景不同，只能做工程量级观察，不能作为同输入受控基准。

parse_perf.py统计每种区间的独立均值；不把各IP时间相加。完整轮次日志中的round包含的边界比ROI total更广，其差值不能无证据归因于某单模块。完整原始串口文件、版本绑定和重复实测仍待作者补充。
