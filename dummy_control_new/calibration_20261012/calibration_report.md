## 公式

标定点转换为 P_robot = R @ P_camera + t。运行时额外抓取补偿单独配置：P_robot = R @ [Xc,Yc,Zc + offset] + t。

```text
Xr = 0.995802681647 Xc - 0.090897752632 Yc - 0.010705969910 (Zc + offset) + 210.949435484601
Yr = -0.001649243099 Xc + 0.099132261865 Yc - 0.995072899166 (Zc + offset) + 410.364041658000
Zr = 0.091511197251 Xc + 0.990913918171 Yc + 0.098566259712 (Zc + offset) + 156.540791067669
```

**当前 offset=20 mm，用户已确认：在相机 Z 方向加20 mm，再转换到机械臂坐标。R、t保持不变。** 以下拟合误差是原始标定点直接转换（offset=0）的残差，不包括额外抓取偏移。直接版本单独保存在 camera_calibration_direct.json，未替换当前 offset 设置。

## 修改与验证

camera_mode_core.py：读取配置内 camera_depth_offset_mm，无此字段时仍保持旧的 +40 mm。
camera_mode_ui.py：标定ID、组数、误差和实际补偿值随配置显示。
camera_calculate.py：离线复算当前文件，默认不写文件，防止旧脚本把历史七组数据写回当前工程。
calibration_20261012/fit_camera_calibration.py：新数据拟合工具；需要显式 --depth-offset-mm，只有提供 --output 时写文件。
测试：93项离线测试通过；由于系统临时目录无写权限，测试临时目录设置在本工程 tests/.tmp_calibration_checks。未连接或驱动实物。
备份：backup_before_camera_7groups_20261012_163107。

## 生效方式

关闭已有摄像头三维控制窗口，再重新打开，窗口创建时会加载最新JSON。也可以完整重启上位机。现有窗口不会自动重读标定参数。
稳定锁定、20mm阈值、3秒新鲜度、J5坐标模型、开闭爪和运动规划逻辑保持原样。

重新生成示例（会写指定文件，不发送硬件命令）：

```powershell
python calibration_20261012/fit_camera_calibration.py --depth-offset-mm 20 --output calibration_20261012/camera_calibration.json
```
