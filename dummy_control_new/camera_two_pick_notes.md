# 摄像头两次抓取与放置

版本：2026-10-12。完整关闭上位机，再通过“launch_legacy.bat”重新启动。

## 使用

1. 在主窗口连接机械臂、使能电机，等待新鲜关节和位姿反馈。
2. 打开“摄像头三维控制模式”，连接 FPGA 串口，勾选原有试验标定运动许可。
3. 等待第一件物体连续至少5个不同帧、跨度至少2秒，各轴极差不超过20 mm，完成坐标锁定。
4. 点击一次“开始两次抓放”。第二件自动继续，不需要再次点击。

|阶段|动作|夹爪状态|
|---|---|---|
|第一次抓取准备|沿用原流程开爪，等待回执及1秒停留|开爪|
|第一次抓取|默认下垂姿态 `(160,0,270)`，再到第一件转换坐标；到位后闭爪|开爪到达、闭爪抓取|
|第一次搬运|回默认下垂姿态，再到 `(0,-150,165)`|保持闭爪|
|第一次放置|确认到位后开爪，等待回执及1秒停留|开爪|
|第一次退出|保持开爪，一次坐标移动到 `(0,-150,210)`，速度30|保持开爪|
|第二次探测|第一次上升完成后解除上位机旧锁定，用新帧重新稳定采集；锁定并通过检查后自动规划|保持开爪|
|第二次抓取|默认下垂姿态，再到第二件转换坐标；到位后闭爪|开爪到达、闭爪抓取|
|第二次搬运|回默认下垂姿态，再到 `(0,-220,165)`|保持闭爪|
|第二次放置|确认到位后开爪，等待回执及1秒停留|开爪|
|第二次退出|保持开爪，一次坐标移动到 `(0,-220,210)`，速度30，本轮结束|保持开爪|

第二次开始时夹爪已经开爪，不重复发送开爪命令。本轮仅执行两件，完成后不会自动抓第三件；再次执行需“重新采集 / 解锁”并重新点击开始。

## 通信与状态

- `camera_pick_place.py` 负责抓放规划、运动/夹爪阶段以及两件的状态管理。主窗口仍使用现有串口协议和 J5 映射。
- 每个运动目标沿用连续三次位置、姿态及关节反馈确认；裸 `ok`、队列回执不能推进后续动作。
- 闭爪前检查抓取点反馈；放置开爪前检查放置点反馈。带物返回和搬运不发送开爪命令。
- 夹爪等待对应逻辑回执及1秒停留。当前硬件命令仍按原映射：物理开爪发送 `!HAND_C`，物理闭爪发送 `!HAND_O`，回执作相应转换。
- 第一次退出到位前不会重新采集。第二次采集忽略退出完成时刻及以前收到的缓存帧，重新累积新稳定帧；沿用新鲜度、质量、范围及偏移检查。
- 第二次检测先过滤补偿后超出标定范围的候选点，无效帧或超范围点清空当前稳定采样，继续等待。只有范围内的有效新帧达到至少5帧、跨度至少2秒且各轴极差不超过20mm，才锁定目标。
- 第二次有效目标锁定后冻结相机输入，后续新坐标、漂移或无效XYZ不会替换目标，也不会因新帧过期取消这个已确认的锁定。运动规划和执行沿用冻结目标；串口断线、STOP、机器人反馈异常等仍会中止本轮。日志增加 `CAMERA_SECOND_FROZEN`。
- “通信锁定打开”实现为上位机清除旧目标、恢复采集，不断开 FPGA 串口，也不发送 FPGA 暂停/恢复命令，HDMI链路保持原行为。
- 所有运动入口的默认速度已统一为30（2026-10-12更新），包括摄像头、手动XYZ、升降、返回、固定下垂预设及J5验证。摄像头两次抓放的所有运动阶段共用首次开始时的速度，默认30；可在开始前修改速度输入框。本轮固定首次开始时的速度。等待第二件时，其他运动和手动夹爪入口不会插入动作。
- STOP、机械臂/FPGA断线、窗口关闭、运动许可撤销或执行异常中止本轮，取消剩余步骤，不自动续跑。查询恢复期间暂停推进，恢复新鲜反馈后继续当前阶段；故障不会自动重试。
- “重新采集 / 解锁”在本轮运行时会中止本轮并请求 STOP，需要重新使能后才能启动新一轮。

## 参数与验证

保持7组新标定和相机 Z +20 mm 补偿；临时增加转换后机械臂 X +10 mm，只作用于两件物体的相机转换抓取目标。默认姿态、放置点和上升点保持原坐标。参数为 camera_calibration.json 的 robot_x_offset_mm，改回0并重启即可取消。放置点为当前模型的基座末端 XYZ，没有增加 TCP 偏移。

107项离线测试通过，涵盖两次完整流程、实际开闭爪协议映射、第一件手动开始/第二件自动开始、旧帧排除、STOP、断线、无夹爪回执、取消夹爪命令不重发、放置未到位不释放及原功能回归。另已在隐藏窗口检查新界面可以创建，串口保持未连接，窗口内容所需高度807像素小于配置的900像素。

本次未驱动实物。参考姿态、横向搬运及放置后上升均采用关节目标运动，途中不保证直线或持续朝下；放置后上升已改为单次关节命令，速度30，不再分段。端点可达检查不包含实物碰撞检查，夹爪回执不表示物体确实夹稳。第二件仍由 FPGA 现有颜色/连通域选择逻辑决定，本次没有添加物体身份识别。
