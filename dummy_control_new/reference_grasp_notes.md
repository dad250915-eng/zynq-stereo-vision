# 参考抓取流程 2026-09-29.9

重启“launch_legacy.bat”生效。手动XYZ和摄像头“开始运动”均采用以下流程：
1. 根据目标自动选取上方过渡点（依次尝试至少30、20、10mm高度差，且不低于当前参考点高度），保留起始朝向到达。
2. 在上方调整到参考程序使用的 R/P/Y=(0,180,0) 姿态。
3. 固定该完整朝向，保持目标X/Y，以不超过2mm间隔下降到输入XYZ。

必须预检全部路径点后才发送第一段。每段等待位置、姿态、关节连续三次反馈合格，才发送下一段。STOP中断剩余流程；显式重新使能和重新下达目标才可开始新流程。通信故障或执行异常中止；通信恢复查询阶段暂停发下一段。

坐标仍是当前模型的机械臂末端参考点。没有添加参考程序中的160mm工具补偿，没有修改电机方向、零位、关节限位或固件。欧拉角反馈可能显示等价的(180,0,180)，以旋转矩阵判断姿态。

上方高度只按运动学可达性选取，不是根据障碍物计算的安全间隙。上方移动和调姿不做碰撞检查。下降段对线性关节插值按10等分进行模型抽样，位置偏差≤0.5mm、朝向偏差≤0.5度，且每段单关节变化≤5度；这不是实机连续轨迹保证，固件仍执行关节目标，可能分段停顿。没有真实硬件轨迹验收，不能宣称与视频动作完全一致或严格直线。

开闭爪仍由用户手动操作；不会在定位结束时自动闭爪。抬起/下降要求当前已处于参考朝下姿态，只分段改变Z；不会重复上方调姿流程。记录/返回姿态仍按所记录关节角返回，可为非抓取姿态。

旧摄像头标定来自任意姿态，需以新的固定抓取姿态重新标定；保留旧转换仅供明确标注的试验使用。
