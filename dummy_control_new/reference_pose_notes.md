# XYZ输入的新流程

每次手动XYZ指令均预检完整路径，然后：
1. 到已验证的参考下垂姿态：模型XYZ=(160,0,270)，固定参考腕部分支。
2. 保持朝下，沿分段路径移动到目标正上方；自动尝试间隙30、20、10 mm。
3. 保持朝下，竖直下降到输入XYZ。

参考点到目标上方可以有斜向位移，不要求水平。除进入参考姿态的首段外，后续各段均检查朝下姿态、关节连续性和模型插值偏差。首次进入参考姿态时会调姿。任一段预检失败则整次不发送。

保持朝下位移分段不超过2 mm；每段等待到位反馈再继续。STOP中止整个流程，不自动续跑，不自动开闭夹爪。独立抬起/下降按钮仍只沿Z移动，不绕行参考点。

J5反向映射保持启用。模型坐标不是夹爪尖端坐标。路径检查不包含障碍物或自碰撞，首次验证请使用低速并确认参考点途经区域有间隙。

相机模式共用新规划器，但旧相机标定仍需在修正模型下重新标定后才能运动。
