# 摄像头三维控制模式与七组数据检查

版本 camera-mode-2026-09-27.4。保留原手动XYZ、记录/返回姿态、串口诊断、只读测试功能。新增窗口，不自动连接、不自动使能、不自动运动。

## 使用

1. 重启启动独立控制.bat，主窗口连接机械臂并按原方式使能。
2. 点击“摄像头三维控制模式”，选择FPGA串口并连接115200。旧控制台/Vitis Serial Terminal必须释放该串口。
3. 保持目标静止，连续5个不同帧、时间跨度至少2秒、XYZ各轴极差不超过5mm后，自动锁定5帧平均值。
4. 窗口显示锁定相机XYZ及转换机械臂XYZ，提示坐标已准备。只锁电脑数据，不向FPGA发送任何命令，不冻结HDMI。
5. 当前转换仅为试验模型，阅读误差后，可勾选“允许本窗口使用上述试验标定运动”，点击“开始运动”。速度默认5，沿用现有自动姿态逆解、关节发送和三次反馈确认。
6. 每次目标最多使用一次，需要下一次运动时点击“重新采集 / 解锁”。STOP在两窗口均可用。

实时有效数据超过3秒未更新、坏帧、帧号倒退或当前目标偏离锁定值超过10mm时不允许开始。已开始动作不随视觉更新重新规划。输入超出这7组相机样本的轴向包围范围时拒绝发送；包围范围不等于精度验证或避障。

## 手动夹爪与升降（hand-lift-2026-09-28.3）
主窗口和摄像头窗口均有“开爪 / 闭爪 / 抬起 Z+ / 下降 Z−”，距离默认100mm、速度默认5（协议速度值），均可改。各步手动点击，不自动串行动作；建议开爪→到物体位置→闭爪并现场确认夹稳→抬起→下降→手动开爪。
开爪发送 !HAND_O，闭爪发送 !HAND_C，对应所提供线轨夹爪源码的电流正负方向控制。沿用固件当前电流参数，不改电流、不自动夹爪校准、不自动独立使能。收到 ok hand open/close 仅表示主控接受，无夹爪到位或夹稳反馈；实际刷入固件须支持该协议。不能据此确认机械STOP能解除夹爪电流。
升降读取新鲜实际XYZABC，保持X/Y及ABC，目标Z加减距离，使用原@位姿接口。Z单位mm，属于基座坐标系；不是电机刻度。下降从当时实际位置减距离，不是自动返回保存点。该接口不保证严格竖直直线轨迹或避障，固定朝向目标不可达时不自动改朝向。等待三次到位反馈后才能下一步。
开闭爪命令等待当前位置查询结束再发送，收到专用回执才解除控制命令等待；2秒回执超时进入故障，不自动重发。记录、返回、摄像头稳定锁定及原有通信诊断保持。实现未执行实机动作。
