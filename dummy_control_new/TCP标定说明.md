# 一次性TCP标定与XYZ执行
版本 tcp-calibration-2026-09-28.5。TCP为两根夹指最前端之间的中心点。

首次操作：
1. 正确初始化机械臂并保持同一连接、同一零位，固定夹爪安装和开口。建立一个固定细尖/十字基准，不让它移动。
2. 打开“一次性TCP / 向下方向标定”。用已有手动控制从不同朝向将TCP中心对准同一点，静止后点击“记录同点样本”。至少5组，朝向需绕至少两个方向变化，不能只平移或只绕一个轴旋转。采集按钮只读反馈，不自动移动。
3. “计算工具偏移”：求解 p_i+R_i t=P固定。检查矩阵秩和条件数；拟合RMS要求≤3mm，最大误差≤5mm；这些是软件筛选值，不是最终抓取精度承诺。
4. 用一个未参加拟合的新姿态（与每个原姿态角差至少3度）对准原固定点，点击“记录独立验证点”，误差须≤5mm。
5. 在有空间的位置，通过原控制功能把夹爪摆为实际竖直向下，静止后点击“记录当前向下朝向”。此时不必对准固定点。软件不能仅凭反馈判断实物安装方向，由使用者现场核对一次。
6. 勾选现场确认，保存tcp_profile.json。没有真实采集和验证数据时，不会生成虚构工具参数或默认零偏移文件。

日常：分步窗口输入基座坐标系下的TCP目标XYZ，点击“TCP：按输入XYZ自动执行”。程序自动加载工具偏移和向下姿态，使用内部过渡高度100mm、X侧偏移30mm、速度30，先检查三步全部有解，再逐步执行到输入点本身，不自动闭爪。不再需要手填ABC、偏移或中间点。保留原高级预览入口。

重要边界：工具几何或夹爪开口改变、装配松动、机器人零位不可重复时需重新标定/验证。保存在文件里不代表实物零位永远有效。端点检查不包含碰撞检测，关节段不保证严格直线或保持中途朝向。固定100mm间隙不是已验证的安全高度。
原七组相机转换是试验性控制器末端目标，不能直接作为TCP坐标，因此TCP模式拒绝复制旧相机目标；先用基座TCP坐标验收，再重采相机与同一个TCP点的对应数据。

本次离线单元与界面测试通过，未连接硬件执行运动。草稿样本存tcp_samples_draft.json，不自动跨会话合并。
