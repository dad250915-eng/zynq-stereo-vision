# 垂直姿态模式 2026-09-28.7

主窗口只输入 XYZ 和速度。已移除自动姿态、固定姿态选项、ABC输入，以及旧分步定位/TCP入口。旧模块和备份保留，不再从界面调用。

手动XYZ、摄像头开始运动、抬起/下降统一约束完整末端旋转为 ABC=(0,0,0)度，采用 Rz(C)Ry(B)Rx(A) 定义：工具-Z指向基座-Z，工具+X指向基座+X。根据用户确认“旧ABC=(180,0,0)导致实际尖端朝上”，将实物夹爪伸出轴按模型-Z处理，目标翻转180度。此修改是基于实物观察的方向修正，离线校验不能替代实机朝向验证；没有修改关节电机方向、零位、L_WRIST或XYZ坐标定义。

XYZ对应当前运动学模型末端参考点（末段L_WRIST=62.5mm），不增加夹爪尖端偏移，不承诺该参考点等于实物J6底面中心。

使用完整位姿逆解，关节限位和舍入后的FK校验均通过才发出 > 关节命令；不会退回任意姿态求解。XYZ误差≤0.5mm、完整姿态误差≤1度且关节误差≤0.3度连续三次合格才显示完成。这些是模型/反馈阈值，不是实物精度保证。

运动为关节目标运动，仅约束最终姿态；未实现笛卡尔直线插补、全程朝下或避障。升降按钮也是Z端点变化，不保证直线路径。STOP、通信检查、开闭爪功能保留。

记录/返回姿态是独立的关节返回功能，保持原有行为，可能返回非垂直姿态。所有XYZ运动必须向下。

旧摄像头7组标定来自任意姿态，不能视为固定朝下抓取标定；应在此新姿态下重新采集。旧试验转换功能保留并明确标注。
