# Dummy 独立 XYZ 控制与诊断

双击“launch_legacy.bat”。程序不依赖 E:\dummy-control 或 FPGA；随附 pyserial/Tcl，优先使用本机已有 Python 运行时。

## 操作

1. 关闭旧控制台对机械臂串口的占用。在本程序刷新端口，选择机械臂串口并连接。连接后只查询，不使能或移动。
2. 点击“使能电机 !START”。收到 Started ok 后，可以发送目标。
3. 输入机械臂**基座绝对 XYZ，单位 mm**，点击“发送XYZ目标”。不设工作范围、不弹出二次运动确认。它不是相机坐标，也不是相对于本次起点的位移。

默认保持最新反馈的 ABC 姿态，只需输入XYZ。若要手动填写ABC，取消对应勾选。位置和姿态按协议保留一位小数。速度默认5，含义是固件速度参数而不是mm/s。按钮“把当前XYZ填入输入框”仅填值，不会移动。

一次发送一个目标。反馈确认到位后提示完成并响铃。未完成时需要中止请按STOP；STOP会取消使能确认，下一动作需再次使能。动作期间再次发送目标会被拒绝，避免堆积未完成命令。

## 按所提供资料实现

- 发送：`@X,Y,Z,A,B,C,speed\n`，与 `D:\dummy\Dummy_Hand\Dummy_Hand\robot_driver.py` 的 move_l 一致。
- 使能：`!START\n`；停止：`!STOP\n`。
- 末端查询：`#GETLPOS\n`；关节查询：`#GETJPOS\n`。
- 对照源码：`D:\dummy\Dummy相关资料\Dummy相关资料\线轨夹爪资料\源码\ascii_protocol.cpp`、`dummy_robot.cpp`。
- 只发送上述协议，不自动HOME、RESET、CALIBRATION、切换CMDMODE、改电流或PID。实际固件版本尚未确认。

## 诊断内容

显示端口名称、VID/PID、串口参数、原始收发、查询往返时间、TX/RX行数、末端XYZABC、六关节角和各自接收年龄。

两种查询返回都是ok加六个数，因此程序严格串行查询。超时后停止交替读取，不把迟到的关节角误当末端位置。发送目标时的队列数字和裸ok只表示协议回复，不当作到位证据。程序按连续三次末端位置及姿态误差判断到位。

诊断提示包括：ESP32启动报错（可能错误通道）、命令无回复、队列拒绝255、查询超时、发令5秒后末端未明显变化、关节接近资料参考限位。参考限位提示不是对实物固件限位的确认，不据此自动运动。

正常有反馈但60秒未到位时只记录提示，继续观察，不重发目标，也不按该时限自动STOP。串口故障时若有未完成目标，尝试一次STOP；失联不能保证停止。进度条仅按位置误差估计，完成还需姿态与三次反馈确认。

## 使用边界

输入XYZ后直接发送，不验证工作空间可达性或碰撞。资料中的MoveL是逆解加关节运动，不保证直线路径；资料源码在某些失败路径仍返回ok，故本程序不能直接得知所有“不动”的根因。日志与六轴反馈用于缩小问题范围，不会假称已诊断出硬件故障。

界面所有操作在用户本地执行。本次开发只做离线测试与窗口启动检查，未连接或驱动实体机械臂。

日志保存到 `logs\console.log`，自动轮转。排查时提供该文件即可，不必另装串口调试软件。


## 2026-09-26 自适应姿态

默认勾选“自动姿态（仅输入XYZ）”。XYZ依然是基座绝对坐标mm，不是每次移动的增量。
只需连接、使能、输入XYZ并发送。无需手填ABC；允许夹爪改变朝向。
电脑用资料中线轨夹爪版本几何参数(134,35,146,117,52,62.5)mm，
按官方SolveFK公式求位置逆解，并以官方 >J1,J2,J3,J4,J5,J6,speed 协议执行。
这是新增的数值逆解，不是把官方固定姿态逆解原样移植；在有限次数搜索中选关节变化较小的解，不能保证全局最优或所有可达点都找到解。
J6保持当前角度。发送前核对新鲜反馈、模型一致性、关节限位及取整后位置残差。
模型一致只说明软件几何匹配，不能验证实物零位、工具尖位置或碰撞。
未找到解时不发送，可直接修改目标重试；不会自动尝试多个运动目标。
求解后台运行，STOP或断开会使未发出的结果失效。
到位要求三次XYZ误差<=0.5mm且六关节误差<=0.3度；不拿ok当作完成。
若已发送却未到位，保留目标状态；先STOP再处理，不自动解锁继续叠加命令。
该模式不含自碰撞、桌面、线缆或障碍物检测；关节插补不是直线路径，也不是抓取姿态规划。
关闭自动姿态后仍保留旧ABC模式。备份在 backup_before_auto_pose。
依赖NumPy，现有启动脚本使用的Python已安装。仅离线测试，未由开发工具发送实机动作。

## 坏帧恢复（2026-09-26）
- RX_RAW 保存每个接收块的十六进制与 bytes 表示；原始块可能包含半行或多行。BAD_FRAME/FAULT/RECOVERY 日志记录处理原因。
- 坏帧不更新位置、不计入到位。使能确认保留，反馈年龄失效；恢复期间禁止使能及新运动，STOP仍可用。已有运动不会因单个坏帧自动中止或重发。
- 暂停交替查询，等待至少2.5秒接收静默，丢弃旧回复，再串行采集两次关节角和两次末端位姿，每次之间均等待静默。
- 稳定性和参考运动学一致性通过后恢复正常查询；取得新鲜关节/末端反馈后解除恢复锁定。探测数据不计入到位。
- 协议没有序号/回复类型，此流程为保守的重新同步，不能提供协议级绝对关联保证。正在运动、模型不匹配或持续异常时可能无法恢复。
- 最多3轮，30秒总期限；失败进入明确故障。如有未完成目标，尝试一次STOP，不能保证实体停止。真USB读写异常仍报错，不自动重连或重发运动。
- 串口故障后使能显示“未知”，不再把软件变量False解释为实体已失能。
- 日志仍在logs/console.log，滚动保留；备份在backup_before_rx_recovery。
- 仅离线验证；本次改动不解决Windows中COM口消失或机械臂零位恢复。

## 记录与返回姿态（2026-09-27）
连接并使能后，在已正确初始化且静止的位置点击“记录返回姿态”。记录三次稳定反馈核对后的实际六关节角，不发送运动。点击“返回记录姿态”按独立返回速度（默认30，协议速度指令而非mm/s）发送官方 > 六关节命令，沿用三次新鲜位置/关节反馈确认完成。不会求解新的自动姿态，不会自动重新使能。XYZ=0,0,0不是返回命令。
记录只在当前连接内有效，不跨重连或程序重启恢复。保持上电使用；软件无法可靠检测所有断电重启，发生断电或零位改变时必须断开重连、核对初始化并重新记录。记录超参考关节限位会拒绝，不自动截断角度。返回只检查端点，不规划避障；先确认途中无碰撞，不保证从任意位置都可直接返回。

## 手动夹爪与升降（hand-lift-2026-09-28.3）
主窗口和摄像头窗口均有“开爪 / 闭爪 / 抬起 Z+ / 下降 Z−”，距离默认100mm、速度默认5（协议速度值），均可改。各步手动点击，不自动串行动作；建议开爪→到物体位置→闭爪并现场确认夹稳→抬起→下降→手动开爪。
开爪发送 !HAND_O，闭爪发送 !HAND_C，对应所提供线轨夹爪源码的电流正负方向控制。沿用固件当前电流参数，不改电流、不自动夹爪校准、不自动独立使能。收到 ok hand open/close 仅表示主控接受，无夹爪到位或夹稳反馈；实际刷入固件须支持该协议。不能据此确认机械STOP能解除夹爪电流。
升降读取新鲜实际XYZABC，保持X/Y及ABC，目标Z加减距离，使用原@位姿接口。Z单位mm，属于基座坐标系；不是电机刻度。下降从当时实际位置减距离，不是自动返回保存点。该接口不保证严格竖直直线轨迹或避障，固定朝向目标不可达时不自动改朝向。等待三次到位反馈后才能下一步。
开闭爪命令等待当前位置查询结束再发送，收到专用回执才解除控制命令等待；2秒回执超时进入故障，不自动重发。记录、返回、摄像头稳定锁定及原有通信诊断保持。实现未执行实机动作。

## 分步定位（staged-pose-2026-09-28.4）
主窗口及摄像头窗口新增“分步定位”入口，原直接运动按钮保持原样。首次需在原控制界面将机械臂调整为所需抓取朝向，待静止后在分步窗口点击“记录当前朝向为抓取朝向”。软件不会猜ABC，也不会自动确认示教朝向是否向下。示教仅本次机械臂连接有效。
输入XYZ或读取主窗口/摄像头锁定目标。默认XYZ含义仍为控制器末端参考点，最后到输入点本身，不自动闭爪。已准确测定工具偏移时，可勾选夹取中心坐标并填写工具局部dx/dy/dz；末端位置按 P末端=P工具-R工具偏移 换算。现有七组试验相机转换没有补偿尖端，不能因此宣称是准确工具坐标。
点击“计算并预览三步”：1. 目标X加侧向偏移（默认30mm），Y不变，Z取当前工具高度与目标Z+间隙（默认100mm）的较大值，保持起始朝向；2. 同一工具过渡点调整为示教朝向；3. 用示教朝向对准输入目标本身。所有三个端点都在后台求解完整XYZABC，任一无解均不发送；参数修改后须重新规划，不自动退回任意姿态。
预览后核对三个端点与整个运动空间，勾选路径确认并点击“开始分步定位”。程序逐步发送关节目标，连续三次位置/关节反馈确认到位后才继续。STOP、连接变化或故障取消后续流程，不自动续跑。正常通信恢复期间暂停推进。相机数据在开始前再次检查；开始后用冻结目标，不随相机更新改轨迹。记录/返回姿态、夹爪和手动运动在规划/分步执行占用期间互斥；STOP可用。
限制：这是端点分步定位，不是碰撞规划或笛卡尔插补。三个端点可达不代表中途安全；关节运动中不保证保持朝向或直线轨迹。转动夹爪时有扫掠空间，向下对准途中仍需检查桌面、物体、机械臂本体和线缆。未知工具偏移或原标定误差不会因拆步自动消失。本次仅离线测试，未驱动实物。
